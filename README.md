# PaulaAlessandra.dev — Portfolio

Portfolio pessoal desenvolvido com foco em performance, design moderno e stack real de produção.

## Stack

- **HTML5** · **CSS3** · **JavaScript**
- **Bootstrap 5.3** — grid, componentes e utilitários
- **Particles.js** — animação de partículas no hero
- **Typed.js** — efeito de digitação dinâmica
- **AOS** — animações ao rolar a página
- **PHP** — backend do formulário de contato

## Funcionalidades

- Dark / Light theme com persistência via localStorage
- Navbar com glassmorphism ao rolar
- Hero com partículas interativas
- Contadores animados (IntersectionObserver)
- Filtro de portfólio por categoria (35+ projetos)
- Formulário de contato com validação e rate limiting
- Layout 100% responsivo (mobile-first)

## Estrutura

```
PaulaAlessandra.dev/
├── index.html
├── contact.php
└── assets/
    ├── css/style.css
    ├── js/script.js
    └── img/
```

## Como rodar localmente

Para o formulário de contato funcionar, é necessário um servidor PHP (XAMPP, Laragon, etc.). Para visualizar o layout, basta abrir o `index.html` no navegador.
